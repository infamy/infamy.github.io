About

I'm Alex, based in British Columbia. Most of my projects start with a radio or gadget whose protocol nobody wrote down: take it apart, document how it works, then build a tool anyone can use. Some of that is security research, like JackIt. Some is day-job work that stays under wraps.

Python and Go for tools and services, C++ for ESP32 firmware, TypeScript for the browser, OpenSCAD for the parts that need printing.

AI tools run through the whole development cycle, from research and design to code, tests and review. That's what keeps this many projects moving at once.

Away from the bench: diving, or somewhere in the BC backcountry.
